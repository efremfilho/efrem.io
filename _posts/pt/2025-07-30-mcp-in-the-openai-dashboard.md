Com a opção de conectar a um MCP Server no Dashboard da Openai, ele tá ficando mais útil para mim do que o próprio ChatGPT para montar "agents". Não entendi o porquê do AI Studio não ter feito a implementação de MCP também.

Falo isso porque não depender mais de um langgraph ajuda DEMAIS a democratizar o uso mais agêntico. Aconselho a qualquer pessoa a usar via o Dashboard e montar um MCP Server na Pipefy/N8N/Zapier. Por sinal, muito kudos para o N8N e de como abstraem o uso do langgraph.

Ah, sempre que eu falo disso, falam do Manus e Perplexity. Conheço muito pouco os dois, mas como já falei no passado, estou focado em entender como os modelos fundacionais fazem e por isso implemento. Recomendo para quem não quer aprender? Não. Usa algo pronto. Muito provavelmente agentes conversacionais como ChatGPT/Gemini vão ter como Claude já tem para usar MCP - outra que conheço pouca é a Anthropic.

Boa exploração no mundo dos MCPs -> que não trazem novidades para quem já usava um langgraph, mas que vai ajudar muito a popularizar o uso de ferramentas por agentes.

Capítulo 8... Está beeeeem mais difícil de construir agora com serviços mais complexos. Nada fora do esperado, mas agora preciso começar a criar "macetes" para conversar com meu time IA.

Uma das coisas escutando o podcast do lenny com o fundador do Cursor me deu de estalo é onde eu estou travando. O iterativo do autocomplete e da localização no código ajuda muito a IA a dar contexto. Ainda não tem uma alternativa boa no programação baseada em chat.

Começou algo de conseguir dizer elementos do front que se quer editar, mas nada ainda visual/para escolher algo que liga o back. Aí que deve começar os macetes para destravar isso. Vou testar alguns essa semana.

Um que já posso adiantar... meus design docs - gerados com o o3 do chatgpt - está piores do que colocar em formato de lista. Ah, essa ideia peguei de como o o3 estava gerando para corrigir o código.

Algo como:

> - conecte com o bd
> - chame a open para subir arquivo pegando da variável tal e tal
> - cria uma vector store
> - associe o arquivo
> - chame a response API.

Isso foi muito melhor que um design doc de 10 páginas.

Outra aventura que tive foi migrar os serviços da API de assistant para a de response só usando o chat. Divertido...podemos dizer. Depois conto mais do processo - ainda tem umas coisas para migrar/apagar.

To be continue...

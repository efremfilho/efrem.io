Tentando migrar para o GPT-5 desde ontem uma aplicação minha. Nossa, está sendo um parto...e dos complicados. É a segunda vez que sofro com isso. Antes foi com a mudança da api assistant para responses.

Sabe o que quebra? Os modelos não tem conhecimento desses novos serviços, aí diz que você está usando o modelo errado e apaga tudo que fez e volta para o default. Tanto o Lovable como o Codex fizeram isso e quebraram toda minha aplicação.

O que fiz de saída? Deep Research ligado ao projeto do github e passando todos os links de como migrar. Ou seja, a pesquisa do como ainda está comigo, mesmo usando o gpt-5. Estou fazendo (no gerúndio mesmo) nesse exato momento para o migração do modelo. No passado funcionou para migração para a API de responses.

Além disso, precisa ficar atento, pq em atualizações seguintes, agentes de código apagam tudo que fizeram pq não "conhecem" as novas implementações.

Boa sorte para quem estiver migrando. \o/

Capítulo 5... mais ~15 horas. Estou convencido que é real que uma pessoa de produto consiga "buildar" com um Lovable. Entretanto, é bem frustante, porém viável, fazer front,back e base de dados.

Agora implementando serviços mais complexos com integração com SendGrid e Openai está sendo difícil, mas não inviável. Manter segurança é um desafio, mas dá também.

O que estou precisando usar:

- Lovable (minha IDE "produteira-friendly")
- GitHub (para buscar trechos do código)
- ChatGPT (com os modelos de reasoning para verificar código e me destravar)
- Supabase (com os logs do edge function)
- Chrome (para usar o console e ver os logs)

Acho que são essas boa parte do tempo.

Ainda é o jeito mais fácil? Nem de perto. Preferiria - AINDA - usar no-code? Sim. Hoje sei bem mais sobre código depois dessas ~80 horas? Com certeza.

MAAAAAAAS acredito que toda pessoa produteira deveria saber e estar usando. Pode criar produtos pedindo como PM é fenomenal.

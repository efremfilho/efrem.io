Chapter 5... another ~15 hours. I'm convinced it's real that a product person can "build" with something like Lovable. However, it's quite frustrating, though feasible, to do front end, back end and database.

Now, implementing more complex services with SendGrid and OpenAI integration has been hard, but not unfeasible. Keeping things secure is a challenge, but it can be done too.

What I'm needing to use:

- Lovable (my "product-person-friendly" IDE)
- GitHub (to look up pieces of the code)
- ChatGPT (with the reasoning models to check code and get me unstuck)
- Supabase (with the edge function logs)
- Chrome (to use the console and see the logs)

I think those are it, most of the time.

Is it the easiest way yet? Not even close. Would I — STILL — prefer to use no-code? Yes. Do I know a lot more about code today after these ~80 hours? For sure.

BUUUUUUUT I believe every product person should know this and be using it. Being able to create products by asking the way a PM does is phenomenal.

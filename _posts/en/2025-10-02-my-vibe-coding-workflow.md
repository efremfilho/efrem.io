This morning two people asked me about my "vibe coding" workflow. I'll leave it on record here:

- Lovable -> the main one, and it takes care of publishing the web app
- Cursor agents -> I use it on the web, and I use it because the models are good, but publishing the code is a bit annoying. The good thing is that Lovable already detects the change
- ChatGPT/Gemini -> Deep research with access to the code, to ask for the PRDs and Design Docs.

That's it. Anyone doing it differently? Remember, I don't use Cursor because it's an IDE (that D makes it clear it's for devs), and I want to be one of the best product people using the tools, not a mediocre dev.

I've been talking to and interviewing a lot of builders these days. It was interesting, but what caught my attention the most was people "abandoning" n8n to build with Claude Code/Cursor instead.

The models (especially Opus 4.7) really have improved a lot. I still notice a difference between people who have some technical knowledge and people who don't. BUT it's not a deal breaker.

To explain: when I ask "change the drawer and build the CRUD", it works much better than when I explain much more than that. Or "change the edge functions to improve the call to that specific model with certain tools" — it gets better.

But is anyone else feeling this? This move away from low-code/no-code tools toward programming by writing text?

Just to be clear, I still really like how n8n forces us to think. It's a UML diagram we can actually test. :) I like to build in it and then ask Claude Code to turn it into code. And for the front end, I still prefer Lovable — not least because it already handles CI/CD and hosting. Oh, and to go to production, when it's not Lovable, I still send it for review by the dev folks.

After a few months with Claude Code, I think I have a better opinion on "why" people who aren't devs and start from scratch think it's amazing, while devs think it's "pero no mucho". In short: legacy.

I'm working on some projects that I started from scratch with coding agents from day one, and on other projects that already existed and that I needed to change. The difference is striking.

When everything was built by the AIs, my commands just glide. Thinking with a product mindset and asking feels like it flows beautifully. But when it comes to code that existed before agents, it seems to get lost.

The big advantage of working on legacy? Working on apps that someone actually uses. :) It's really boring to build things nobody uses. :P

We forget that code carries a lot of opinions, and it's always hard for anyone to join a project that's already in motion, AI or little human... buuuut it's impressive how I, a really bad dev, can deliver things I never dreamed of.

Oh, and OBVIOUSLY I had to learn a lot of technical stuff. I even feel more like a dev today. As I've always said, no-code was never about coding, but about delivering value faster.

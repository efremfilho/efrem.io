For me, this is the problem with vibe coders. They think the code is the hard part. It isn't. It's everything else about keeping software up and secure. The hyper-personalization of an app is real. I need it for my own case and I build an app? That already works, and very well.

Am I going to build it for lots of people to use? Not so much. That's going to be a headache. When people ask me why I still use Lovable alongside Claude Code, this is why. I don't want to worry about setting up CI/CD processes, prod and dev environments, etc.

This is temporary. We'll get to the point where it's super easy. In my use of Claude Code, spinning up servers with policies configured and so on is no big deal. Does that mean it's done the best way? No way. I'm not a dev. As I say, I want to be a better product person. Whatever part of the dev process I can outsource to tools, I will.

For now. lol
